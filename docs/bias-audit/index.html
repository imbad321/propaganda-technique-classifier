bias_audit

A small library for one specific question: did your text classifier learn the task, or did it learn a proxy for the task instead - the outlet a sentence came from, the register of the writing, anything correlated with the label but not actually it?

Where this fits

This is a narrower, more practical cousin of ideas from the shortcut-learning / spurious-correlation literature (group-robustness work like Sagawa et al.'s group-DRO, behavioral testing like Ribeiro et al.'s CheckList) and of general fairness toolkits (Fairlearn, AIF360, Aequitas). Those are broader - built mostly around tabular data and demographic-parity style metrics. bias_audit is aimed squarely at multi-label text classifiers and the specific failure mode of "the model fingerprinted the source instead of reading the content," with two things bundled in that general toolkits don't hand you out of the box: a single gap-penalized effectiveness score, and a label-reliability check for your own ground truth.

Install

pip install -e ./bias_audit

Usage

from bias_audit import Classifier, LabeledExample, audit, label_reliability

# 1. Wrap your model so it can score raw text against your label set.
class MyClassifier:
    def predict_proba(self, texts):
        ...  # returns an (n_texts, n_labels) array of scores in [0, 1]

# 2. Build a labeled, group-tagged evaluation set. `group` is any categorical
#    split you're worried the model might be keying off of instead of content -
#    outlet lean, dialect, age bracket, whatever applies to your problem.
examples = [
    LabeledExample(text="...", labels=[1, 0, 0], group="left"),
    LabeledExample(text="...", labels=[0, 1, 0], group="right"),
]

# 3. Audit it.
report = audit(MyClassifier(), examples, label_names=["a", "b", "c"])
print(report.summary())
print(report.effectiveness_score)   # overall F1_macro minus the max group-to-group gap

# 4. Optional: check your own ground truth against a second labeler first -
#    a low kappa on one label means that label's ground truth is the noisy
#    part, not necessarily the model.
reliability = label_reliability(your_labels, second_labeler_labels, label_names=["a", "b", "c"])
print(reliability.summary())

API

LabeledExample(text, labels, group)

One example.

Classifier

A Protocol with one method: predict_proba(texts) -> np.ndarray. Wrap any model in it.

audit(classifier, examples, label_names, thresholds=0.5)

Main entry point. Returns an AuditReport: overall + per-group F1, max group gap, effectiveness score.

evaluate_predictions(y_true, y_pred, label_names)

Lower-level piece if you already have predictions.

label_reliability(labels_a, labels_b, label_names)

Per-label Cohen's kappa, exact-match rate, mean Jaccard between two labelers.

load_labeled_jsonl(path, ...)

Reads a JSONL file straight into LabeledExamples.

Worked example

Extracted from propaganda-technique-classifier, a multi-label propaganda-technique classifier - it's the model this library was built to audit. Applied there: effectiveness score 0.203 on a 150-sentence, hand-labeled, source-blind evaluation set spanning left/center/right-leaning outlets, plus a 0.426 mean Cohen's kappa checking the ground truth itself against a second, independent labeling. See the project page for the full write-up.

The core idea here isn't new - it's a narrow, practical slice of an active research area. What's less common is finding it packaged as reusable code instead of a one-off number in a results table.
